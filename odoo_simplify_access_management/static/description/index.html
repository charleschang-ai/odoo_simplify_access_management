See it in action: before & after

All screenshots below come from the same user (a salesperson) — left without a profile, right after applying one access profile. Nothing else was changed. (Screenshots taken on the Odoo 20 interface; the Odoo 19 screens look almost identical.)

01 · MENUS

Show each team only the apps they need

Purchase, Invoicing, Employees, Dashboards, Sales/Reporting and Sales/Configuration are gone for this salesperson – and so are all their sub-menus. Simply pick menus from a list.

02 · FIELDS, BUTTONS, TABS & CHATTER

Fine-grained control inside every form

On the same quotation, the restricted user no longer has the Preview and Cancel buttons, the Other Info tab, nor Send message and Activity in the chatter. Payment Terms became read-only, Expiration is mandatory, and Unit Price can no longer be changed.

Field rules are applied to the view and enforced on write: even if someone forges a request, a read-only field cannot be modified.

03 · RECORD RULES

“Only my own orders” – enforced at data level

One line – [('user_id', '=', user.id)] – and the salesperson sees 13 of their own orders instead of all 21. The domain is turned into a real Odoo record rule (ir.rule), so opening another order directly by URL or ID is refused by the server. Supports user, uid, company_id, company_ids and time, with separate read / write / create / delete checkboxes.

Opening someone else’s order by URL → Access Error.

04 · FILTERS, GROUP BY & VIEW TYPES

A cleaner search panel and only the views that matter

“Group by Salesperson” and “To Upsell” disappear from the search panel; Pivot, Graph, Map and Cohort disappear from the view switcher – no more peeking at team-wide analytics.

05 · MODEL RULES, ACTIONS & REPORTS

No delete, no duplicate, no export – where you decide

On Sales Orders, Duplicate and Delete are gone together with the Share, Save as template and Close Invoicing actions and the PRO-FORMA report. On Contacts the New button disappears – and creating a contact through the API is refused too.

FAQ

Is it only hiding things in the interface?
No. Model, field, record, chatter, import/export, module and API restrictions are checked on the server. Calling the method directly, opening a record by URL or using XML-RPC is refused.
Does it replace Odoo’s user groups?
It works on top of them. Keep your groups for the basic rights and use profiles to restrict further – per user, per group or per company.
Do I need to restart Odoo or ask users to log out?
No. Changes apply immediately and the affected users’ browsers reload automatically.
Does it work with Community and Enterprise?
Yes, both editions of Odoo 19, on-premise and Odoo.sh.
